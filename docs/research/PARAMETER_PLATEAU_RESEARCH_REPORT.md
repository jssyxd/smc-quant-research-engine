## 一、为什么放弃“孤立最优点”？我们是如何做“参数平原”测试方案的？

### 1. 孤立最优点（Spike Overfitting）的致命危害
在量化回测中，许多策略宣称在某个单一参数（例如 $\text{ATR} = 2.15$、$\text{Score} = 65$）获得了漂亮的资金曲线，但稍作变动（如 ATR 变为 2.10 或 2.20），收益立刻断崖式转为亏损。这种孤立尖峰在统计学上是纯粹的市场噪声拟合。实盘时市场波动率轻微漂移，该策略必死无疑。

### 2. 参数平原方案设计架构
我们在 `scripts/parameter_plateau_runner.py` 与 `autoresearch.sh` 中设计了 **2D 连续参数平原敏感度矩阵**：
- **X 轴：SMC 综合共振打分阈值 (`Score Threshold`)**：`[60.0, 65.0, 70.0, 75.0]`（对应 3/5 到 5/5 因子共振门槛）；
- **Y 轴：止损/跟踪 ATR 倍数 (`ATR Multiplier`)**：`[1.80, 1.90, 2.00, 2.10, 2.15, 2.20, 2.30, 2.40, 2.50]`（覆盖 2.15 及其周围的连续平原邻域）；
- **平原稳定性度量算法（Plateau Stability Score, PPSS）**：
  $$PPSS = \frac{\text{WinRatio}_{\text{neighborhood}}}{1 + CV} \times 100$$
  其中 $CV = \sigma / |\mu|$ 为邻域变异系数，$\text{WinRatio}$ 为邻域正收益率占比。该指标惩罚单点尖峰，只奖励在连续宽带参数内平稳盈利的系统。

## 五、第二梯队标的（AVAX, LINK）纳入与同一笔 1000 元资金相撞实测

   AVAX 与 LINK 作为高 Beta Layer-1 / 预言机龙头，顺势延展性良好；在共享资金池下成功分摊了单币特异性风险，使得核心平原平均回撤从基准的 9.78% 压低至 **5.98%**。
